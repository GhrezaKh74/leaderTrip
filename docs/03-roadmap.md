## فاز ۱ — هستهٔ برنامه‌ریز (MVP)

**قول فاز:** کاربر ورودی‌ها را می‌دهد و یک برنامهٔ کامل روزبه‌روز با تفکیک هزینه و نقشه می‌گیرد.
**تخمین:** بزرگ‌ترین فاز — حدود ۵۵٪ کل کار.

### کارها

**داده**
- [ ] `cities.ts` — حدود ۶۰ شهر با مختصات، ضریب گرانی، سطح امکانات
- [ ] `pois.ts` — حداقل ۱۲۰ جاذبه با همهٔ فیلدهای مدل داده
- [ ] `vehicles.ts` — حدود ۱۵ پروفایل خودروی رایج ایران
- [ ] `pricing.ts` — همهٔ ضرایب سند مدل هزینه

**موتور**
- [ ] `geo.ts` — هاورساین، ضریب پیچش، مرکز ثقل
- [ ] `sun.ts` — طلوع و غروب
- [ ] `scoring.ts` — امتیازدهی مبتنی بر پروفایل گروه
- [ ] `router.ts` — نزدیک‌ترین همسایه + ۲-opt
- [ ] `planner.ts` — خوشه‌بندی روزها + زمان‌بندی
- [ ] `cost.ts` — همهٔ اقلام هزینه با `formula` قابل نمایش

**کتابخانه**
- [ ] `jalali.ts` — تبدیل شمسی/میلادی + نام ماه‌ها
- [ ] `format.ts` — اعداد فارسی، تومان، مدت‌زمان
- [ ] `storage.ts` — ذخیره و بازیابی سفرها

**رابط کاربری**
- [ ] ویزارد ۵ گامی: مقصد ← تاریخ ← همسفران ← خودرو ← بودجه و سلیقه
- [ ] صفحهٔ برنامه: تایم‌لاین روزها
- [ ] پنل هزینه: نمودار تفکیک + جدول قابل بازکردن + ویرایش ضرایب
- [ ] نقشهٔ Leaflet با نشانگرهای شماره‌دار و خط مسیر
- [ ] کارت جاذبه با همهٔ برچسب‌های تناسب

**تست**
- [ ] تست واحد برای `cost`، `geo`، `jalali`، `router`
- [ ] CI: typecheck + lint + test + build
