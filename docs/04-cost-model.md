# ۴. موتور هزینه — فرمول‌ها و ضرایب

> این سند **قرارداد محاسباتی** محصول است. هر عددی که در UI نمایش داده می‌شود باید دقیقاً از این فرمول‌ها بیرون بیاید.
> واحد همه‌جا **تومان** است. همهٔ ضرایب در فایل `src/data/pricing.ts` قرار می‌گیرند و **در رابط کاربری قابل ویرایش‌اند**.

---

## ۴.۰ اصل شفافیت

هر قلم هزینه یک شیء با این شکل تولید می‌کند تا کاربر بتواند «چرا این عدد؟» را ببیند:

```ts
interface CostLine {
  key: string          // 'fuel'
  label: string        // 'سوخت'
  amount: number       // 3_120_000
  formula: string      // '۸۲۰ کیلومتر × ۸.۵ لیتر/۱۰۰کیلومتر × ۳٬۰۰۰ تومان'
  editable: boolean
}
```

---

## ۴.۱ مسافت و زمان

اپ سرور مسیریابی ندارد؛ فاصلهٔ هوایی را با **ضریب پیچش جاده** به فاصلهٔ جاده‌ای تبدیل می‌کنیم:

```
مسافت هوایی  = haversine(A, B)
مسافت جاده‌ای = مسافت هوایی × ضریب پیچش
```

| نوع منطقه | ضریب پیچش |
|---|---|
| دشت / آزادراه | ۱٫۱۵ |
| پیش‌فرض (نامشخص) | ۱٫۲۵ |
| کوهستانی | ۱٫۴۵ |
| جادهٔ فرعی و خاکی | ۱٫۶۰ |

**زمان رانندگی:**

```
سرعت مؤثر = سرعت پایه × ضریب خودرو × ضریب منطقه × ضریب گروه
زمان (دقیقه) = مسافت جاده‌ای ÷ سرعت مؤثر × ۶۰
```

- سرعت پایهٔ برون‌شهری: **۸۵ کیلومتر بر ساعت**
- ضریب خودرو: سواری ۱٫۰ · شاسی‌بلند ۰٫۹۵ · ون ۰٫۹۰ · مینی‌بوس ۰٫۸۰ · اتوبوس ۰٫۷۵ · موتورسیکلت ۰٫۸۵
- ضریب منطقه: دشت ۱٫۰ · کوهستان ۰٫۷۵ · خاکی ۰٫۵
- ضریب گروه: اگر کودک زیر ۶ سال یا فرد بالای ۷۰ سال در جمع باشد **۰٫۹۰**
  (توقف‌های بیشتر — علاوه بر بلوک‌های استراحت که جداگانه در برنامه درج می‌شوند)

> ✅ **از فاز ۵ این محدودیت برداشته شد.** اگر اینترنت در دسترس باشد، مسافت و زمان
> از **مسیر واقعی جاده** (OSRM) گرفته می‌شود و همین‌ها مبنای سوخت، عوارض و اهلاک‌اند.
> فرمول بالا هم‌چنان به‌عنوان **پشتیبان** می‌ماند: بدون شبکه، همان تخمین با خطای
> ±۱۵٪ استفاده می‌شود و رابط کاربری صریحاً «تخمینی» برچسب می‌زند تا کاربر بداند
> با کدام‌یک طرف است.
>
> زمانِ OSRM برای یک خودروی معمولی در جادهٔ خلوت است، پس ضریب خودرو و ضریب گروه
> همچنان روی آن اعمال می‌شوند — اتوبوس و گروهِ با کودک واقعاً کندترند.

## ۴.۲ سوخت

```
لیتر مصرفی = (مسافت کل جاده‌ای ÷ ۱۰۰) × مصرف خودرو × ضریب بار × ضریب کوهستان
هزینهٔ سوخت = لیتر مصرفی × قیمت هر لیتر × تعداد خودرو
```

- **ضریب بار:** `1 + 0.03 × max(0, سرنشین − ۲)` — هر سرنشین اضافه ۳٪ مصرف بیشتر (سقف ۱٫۲)
- **ضریب کوهستان:** ۱٫۱۵ برای بخش‌های کوهستانی مسیر
- خودرو برقی: به‌جای لیتر، `kWh` و قیمت هر کیلووات‌ساعت

**قیمت پیش‌فرض سوخت (تومان بر لیتر) — قابل ویرایش:**

| سوخت | نرخ سهمیه‌ای | نرخ آزاد |
|---|---|---|
| بنزین | ۱٬۵۰۰ | ۳٬۰۰۰ |
| گازوئیل | ۴۰۰ | ۱٬۵۰۰ |
| گاز (CNG) | ۶۰۰ | — |
| برق (هر kWh) | ۱٬۰۰۰ | — |

کاربر انتخاب می‌کند چه سهمی از سوخت با نرخ سهمیه‌ای تأمین می‌شود (پیش‌فرض: ۶۰٪).

```
قیمت مؤثر = سهم سهمیه × نرخ سهمیه‌ای + (۱ − سهم سهمیه) × نرخ آزاد
```

> این جدول با تغییر قیمت‌های ملی سوخت **باید به‌روزرسانی شود**؛ در UI تاریخ آخرین به‌روزرسانی نمایش داده می‌شود.

---

## ۴.۳ عوارض

```
هزینهٔ عوارض = مسافت جاده‌ای × سهم آزادراه × نرخ عوارض هر کیلومتر × تعداد خودرو
```

- سهم آزادراه پیش‌فرض: **۴۵٪** مسیر برون‌شهری
- نرخ پیش‌فرض: **۳۰۰ تومان بر کیلومتر** برای سواری
- ضریب کلاس خودرو: سواری ۱٫۰ · ون ۱٫۵ · مینی‌بوس ۲٫۰ · اتوبوس ۳٫۰ · موتور ۰
- عوارض ورود به محدودهٔ شهرها و تونل‌های خاص در فاز ۲ به‌صورت موردی افزوده می‌شود

---

## ۴.۴ اقامت

```
هزینهٔ اقامت = Σ (شب‌ها) نفرات × نرخ پایهٔ سطح × ضریب گرانی شهر × ضریب فصل
```

**نرخ پایه — تومان به ازای هر نفر در هر شب:**

| سطح سفر | نوع اقامت | نرخ پایه |
|---|---|---|
| اقتصادی | کمپ / مسافرخانه / هاستل | ۴۰۰٬۰۰۰ |
| متعادل | بوم‌گردی / هتل ۲–۳ ستاره | ۹۰۰٬۰۰۰ |
| راحت | هتل ۴ ستاره / ویلا | ۱٬۸۰۰٬۰۰۰ |
| لوکس | هتل ۵ ستاره | ۴٬۰۰۰٬۰۰۰ |

- **ضریب گرانی شهر** (`City.costIndex`): تهران ۱٫۳ · کیش ۱٫۴ · اصفهان/شیراز ۱٫۰ · شهر کوچک ۰٫۷۵
- **ضریب فصل:** نوروز و تعطیلات رسمی ۱٫۶ · تابستان در شمال و سواحل ۱٫۳ · فصل عادی ۱٫۰
- **تخفیف کودک:** زیر ۳ سال رایگان، ۳ تا ۱۰ سال ۵۰٪
- **بهینه‌سازی اتاق:** اگر گزینهٔ «اتاق مشترک» فعال باشد، هزینه بر پایهٔ اتاق دو/سه‌تخته محاسبه می‌شود، نه نفر
- کمپینگ: نرخ صفر + هزینهٔ یک‌بارهٔ تجهیزات (اختیاری)

---

## ۴.۵ خوراک

```
هزینهٔ خوراک = Σ (وعده‌ها) نفرات × نرخ وعده × ضریب گرانی شهر × ضریب سن
```

**نرخ پایه — تومان به ازای هر نفر در هر وعده:**

| سطح | صبحانه | ناهار | شام |
|---|---|---|---|
| اقتصادی | ۸۰٬۰۰۰ | ۲۵۰٬۰۰۰ | ۲۵۰٬۰۰۰ |
| متعادل | ۱۵۰٬۰۰۰ | ۴۵۰٬۰۰۰ | ۴۵۰٬۰۰۰ |
| راحت | ۲۵۰٬۰۰۰ | ۸۰۰٬۰۰۰ | ۸۰۰٬۰۰۰ |
| لوکس | ۴۵۰٬۰۰۰ | ۱٬۵۰۰٬۰۰۰ | ۱٬۵۰۰٬۰۰۰ |

- ضریب سن: زیر ۶ سال ۰٫۴ · ۶ تا ۱۲ سال ۰٫۷ · بقیه ۱٫۰
- گزینهٔ «غذای خانگی همراه»: هر وعدهٔ علامت‌خورده ۸۰٪ ارزان‌تر می‌شود
- تنقلات/نوشیدنی بین‌راهی: **۱۵٪** روی جمع خوراک

## ۴.۶ بلیت جاذبه‌ها

```
هزینهٔ بلیت = Σ (جاذبه‌های برنامه) Σ (نفرات) بلیت پایه × ضریب سنی
```

| گروه سنی | ضریب |
|---|---|
| زیر ۵ سال | ۰ (رایگان) |
| ۵ تا ۱۲ سال | ۰٫۵ |
| ۱۳ تا ۶۴ سال | ۱٫۰ |
| ۶۵ سال به بالا | ۰٫۷ |

## ۴.۷ اهلاک خودرو

قلمی که تقریباً همه فراموشش می‌کنند، ولی واقعاً پول است:

```
هزینهٔ اهلاک = مسافت کل × نرخ اهلاک هر کیلومتر × تعداد خودرو
```

**نرخ پیش‌فرض (تومان بر کیلومتر):**

| کلاس خودرو | نرخ | شامل |
|---|---|---|
| موتورسیکلت | ۳۰۰ | روغن، لاستیک، زنجیر |
| سواری اقتصادی | ۹۰۰ | روغن، لاستیک، فیلتر، لنت |
| شاسی‌بلند | ۱٬۵۰۰ | همان + مصرف بالاتر قطعات |
| ون | ۱٬۷۰۰ | |
| مینی‌بوس | ۲٬۵۰۰ | |
| اتوبوس | ۴٬۰۰۰ | |
| برقی | ۴۰۰ | نگهداری کمتر |

## ۴.۸ متفرقه و بافر ریسک

```
زیرجمع = سوخت + عوارض + اقامت + خوراک + بلیت + اهلاک + سایر اقلام دستی
متفرقه = زیرجمع × نرخ متفرقه       (سوغات، پارکینگ، انعام، سرویس بهداشتی)
بافر   = (زیرجمع + متفرقه) × نرخ بافر
جمع کل = زیرجمع + متفرقه + بافر
```

| سطح سفر | نرخ متفرقه | نرخ بافر |
|---|---|---|
| اقتصادی | ۵٪ | ۱۰٪ |
| متعادل | ۸٪ | ۱۲٪ |
| راحت | ۱۰٪ | ۱۲٪ |
| لوکس | ۱۵٪ | ۱۵٪ |

## ۴.۹ سه سناریو

برای اینکه کاربر بداند با چه بازه‌ای طرف است:

| سناریو | ضریب روی جمع کل |
|---|---|
| خوش‌بینانه | ۰٫۸۵ |
| محتمل (پیش‌فرض) | ۱٫۰۰ |
| بدبینانه | ۱٫۲۵ |

خروجی اصلی همیشه به شکل بازه هم نمایش داده می‌شود: «۲۴ تا ۳۵ میلیون تومان، محتمل ۲۸ میلیون».

## ۴.۱۰ تقسیم بین نفرات

سه حالت:

1. **مساوی:** جمع کل ÷ تعداد بزرگسالان (کودکان سهم ندارند مگر کاربر بگوید)
2. **وزنی:** هر نفر ضریب دارد (مثلاً کودک ۰٫۵)
3. **تفکیکی:** هزینه‌های مشترک (سوخت، عوارض، اهلاک) مساوی؛ هزینه‌های شخصی (بلیت، غذا، اقامت) بر اساس مصرف واقعی همان فرد

خروجی: جدول «هرکس چقدر بدهکار است» + سهم پرداخت‌شده تا این لحظه.

## ۴.۱۱ بهینه‌سازی بودجه

اگر `جمع کل > بودجه`، موتور به ترتیب این اهرم‌ها را امتحان می‌کند و **هر پیشنهاد را با میزان صرفه‌جویی** نشان می‌دهد:

| # | اهرم | صرفه‌جویی تقریبی |
|---|---|---|
| ۱ | یک سطح پایین‌آوردن اقامت | ۳۰–۵۰٪ از اقلام اقامت |
| ۲ | تبدیل یک شب به کمپینگ | ۱۰۰٪ از آن شب |
| ۳ | حذف کم‌امتیازترین جاذبه‌های دور از مسیر | بلیت + سوخت انحراف |
| ۴ | جایگزینی وعده‌های رستوران با غذای همراه | ۸۰٪ از آن وعده |
| ۵ | کوتاه‌کردن شعاع سفر | متناسب با کیلومتر |
| ۶ | کاهش یک روز از سفر | حدود ۱/n کل |

اپ **خودکار برنامه را عوض نمی‌کند**؛ گزینه‌ها را با عدد نشان می‌دهد و کاربر انتخاب می‌کند.

## ۴.۱۲ سلب مسئولیت (در UI هم نمایش داده می‌شود)

> همهٔ ارقام **تخمینی** و بر پایهٔ قیمت‌های پایهٔ قابل‌ویرایش‌اند.
> قیمت واقعی سوخت، اقامت و بلیت با زمان و مکان تغییر می‌کند.
> پیش از سفر قیمت‌های پایه را به‌روز کنید.
