# 🧭 لیدرتریپ — LeaderTrip

**دستیار هوشمند لیدر سفر:** با گرفتن تاریخ، مبدأ، خودرو، همسفران و بودجه،
یک **برنامهٔ سفر ساعت‌به‌ساعت شدنی** با **تخمین هزینهٔ قابل‌ردیابی تا آخرین ریال** می‌سازد.

> بقیهٔ اپ‌ها می‌گویند «کجا زیباست».
> لیدرتریپ می‌گوید «با **این** ماشین، **این** آدم‌ها و **این** بودجه، دقیقاً چه چیزی شدنی است و چقدر خرج برمی‌دارد».

## قابلیت‌های هدف

- 🗺️ **کشف جاذبه‌ها** در شعاع دلخواه از مبدأ، متناسب با علایق گروه
- 📅 **برنامهٔ روزبه‌روز** با احترام به سقف رانندگی و ساعت روشنایی
- 💰 **تخمین دقیق هزینه**: سوخت، عوارض، اقامت، خوراک، بلیت، اهلاک خودرو، بافر ریسک
- 👨‍👩‍👧‍👦 **تناسب با افراد**: سن، تحرک و توان جسمی همه در الگوریتم لحاظ می‌شود
- 🚙 **تناسب با خودرو**: مسیر خاکی برای سواری پیشنهاد نمی‌شود
- 🌦️ **آب‌وهوا-محور**: باران و گرما برنامه را واقعاً تغییر می‌دهند
- 🎒 **ابزار لیدر**: چک‌لیست بار، تقسیم هزینه، خروجی چاپی

## اصول فنی

- **بدون بک‌اند** — همهٔ موتور در مرورگر اجرا می‌شود
- **بدون کلید API** — تنها سرویس بیرونی (Open-Meteo) رایگان و اختیاری است
- **آفلاین-اول** — دادهٔ جاذبه‌ها همراه اپ است
- **بدون لاگین** — داده روی دستگاه خودتان می‌ماند

## استک

Vite · React 19 · TypeScript · Tailwind CSS · Leaflet · Open-Meteo
