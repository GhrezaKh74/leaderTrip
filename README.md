# 🧭 لیدرتریپ — LeaderTrip

**دستیار هوشمند لیدر سفر:** با گرفتن تاریخ، مبدأ، خودرو، همسفران و بودجه،
یک **برنامهٔ سفر ساعت‌به‌ساعت شدنی** با **تخمین هزینهٔ قابل‌ردیابی تا آخرین ریال** می‌سازد.

> بقیهٔ اپ‌ها می‌گویند «کجا زیباست».
> لیدرتریپ می‌گوید «با **این** ماشین، **این** آدم‌ها و **این** بودجه، دقیقاً چه چیزی شدنی است و چقدر خرج برمی‌دارد».

## وضعیت پروژه

✅ **هر پنج فاز کامل شدند** (به‌جز رابط انگلیسی، که [عمداً](docs/03-roadmap.md) کنار گذاشته شد).

✅ **بازنویسی هم کامل شد** ([سند ۶](docs/06-rewrite-architecture.md)): بک‌اند
NET 10. با معماری تمیز در `backend/` و رابط React 19 + MUI در `web/` — با
طراحی اختصاصی، تقویم سراسر شمسی، عکس چک‌این سمت سرور، پنل مدیریت و حساب
کاربری با «سفرهای من». همین نسخه است که داکر بالا می‌آورد؛ نسخهٔ اول در
`src/` تا تصمیم نهایی بازنشستگی سر جایش است.

برنامهٔ ساعت‌به‌ساعت، تفکیک هزینه با فرمول هر قلم، نقشهٔ مسیر، آب‌وهوای
تأثیرگذار، مشاور هشدارها، بهینه‌ساز بودجه، چک‌لیست بار، ویرایش دستی،
نسخهٔ چاپی، اشتراک‌گذاری با لینک، کارکرد کامل آفلاین، و حالت حین سفر با
تسویه‌حساب گروهی.

مسافت‌ها حالا از **مسیر واقعی جاده** می‌آیند، و بدون اینترنت به تخمین
برمی‌گردند — با برچسب صریح که کدام است.

## آنچه امروز کار می‌کند

- **۱۴۳ جاذبه و ۸۵ شهر** سراسر ایران با مختصات، مدت بازدید، بلیت، سختی مسیر و تناسب سنی
- **۱۵ پروفایل خودرو** از پراید تا اتوبوس، با مصرف سوخت و توان آفرود واقعی
- **موتور برنامه‌ریزی** با احترام به سقف رانندگی، ساعت واقعی طلوع و غروب، و توان جسمی گروه
- **موتور هزینه** با ۸ قلم تفکیک‌شده که هرکدام فرمول خودش را نشان می‌دهد
- **آب‌وهوای تأثیرگذار**: باران جاذبه‌های سرپوشیده را جلو می‌اندازد، گرما روز را
  زودتر شروع می‌کند و استراحت نیم‌روزی می‌گذارد، برف سرعت مسیر را کم می‌کند
- **مشاور**: هشدار خستگی رانندگی، فشار جسمی، خودروی نامناسب، بودجه و نکات اقلیمی
- **بهینه‌ساز بودجه**: هفت راه کاهش هزینه، هرکدام با عدد صرفه‌جویی واقعی
- **چک‌لیست بار** متناسب با فصل، اقلیم، نوع اقامت و اعضای گروه
- **پین و حذف جاذبه** و **توقف دلخواه**: حرف آخر را کاربر می‌زند، نه الگوریتم
- **ویرایش دستی**: جابه‌جایی هر بازدید بین روزها
- **نسخهٔ چاپی کامل**: برنامه، هزینه، شماره‌های اضطراری و چک‌لیست روی کاغذ
- **اشتراک‌گذاری با لینک** (حدود ۵۰ کاراکتر، بدون سرور) و خروجی/ورودی JSON
- **نصب روی گوشی و کارکرد آفلاین** — در جادهٔ بدون آنتن هم باز می‌شود
- **حالت حین سفر**: چک‌این هر توقف با ساعت واقعی و اختلافش با برنامه،
  یادداشت و عکس، ثبت هزینهٔ واقعی، گزارش «تخمین در برابر واقعیت» و
  تسویه‌حساب گروهی با کمترین تعداد جابه‌جایی پول
- **مسیر واقعی جاده** (OSRM) به‌جای تخمین، هرجا اینترنت باشد
- **هشدار گردنهٔ مرتفع** بر پایهٔ ارتفاع واقعی نقاط مسیر
- **کشف از OpenStreetMap** برای جاهایی که در فهرست ما نیستند
- **یادگیری سلیقه** از امتیازهایی که به توقف‌های سفرهای قبل داده‌اید
- تقویم شمسی، رابط راست‌به‌چپ و حالت تاریک

## اجرا با داکر (توصیه‌شده)

```bash
cp .env.example .env             # و POSTGRES_PASSWORD را پر کنید
docker compose up -d --build     # ساخت و اجرا در پس‌زمینه
```

و تمام — رابط روی <http://localhost:8080> بالا می‌آید و همان‌جا `/api` را به
بک‌اند پروکسی می‌کند؛ مرورگر همه‌چیز را از یک مبدأ می‌بیند، CORS بسته می‌ماند
و توکن حساب به مبدأ غریبه نمی‌رود. بک‌اند برای دسترسی مستقیم (اشکال‌زدایی)
روی <http://localhost:8081> هم هست. پنل مدیریت: `/?admin` (با
`ADMIN_API_KEY`).

```bash
docker compose logs -f             # دیدن لاگ‌ها
docker compose down                # توقف
PORT=3000 docker compose up -d     # روی پورت دلخواه
docker compose --profile dev up    # حالت توسعه با بارگذاری زنده
docker compose --profile tiles up  # نقشهٔ خودمیزبان ایران (یک‌بار؛ maps/README.md)
```

با `restart: unless-stopped` بعد از ریستارت سرور یا کرش، خودکار بالا می‌آید.

**سه سرویس بالا می‌آید:** رابط کاربری (nginx، از `web/`)، بک‌اند .NET، و
PostgreSQL. بک‌اند بدون پایگاه داده هم کار می‌کند — دادهٔ مرجع همراهش است —
ولی آن‌وقت قیمت‌ها فقط‌خواندنی‌اند و حساب‌های کاربری با هر راه‌اندازی می‌پرند.
عکس‌های چک‌این روی volume جدا می‌مانند (`photo-data`) و مایگریشن‌های پایگاه
داده هنگام بالاآمدن بک‌اند خودکار اجرا می‌شوند.

**چند نکتهٔ عمدی در پیکربندی:**

- **تست بخشی از بیلد است** — ایمیجی که تستش قرمز است ساخته نمی‌شود.
- **`sw.js` هرگز کش نمی‌شود.** اگر کش شود، کاربر برای همیشه روی نسخهٔ
  قدیمی گیر می‌کند، چون همان سرویس‌ورکرِ کهنه است که تصمیم می‌گیرد چه چیزی
  به‌روز شود. در مقابل، دارایی‌های `assets/` نامشان هش دارد و کش یک‌ساله
  می‌گیرند.
- **کاربر غیر root و فایل‌سیستم فقط‌خواندنی.** به همین دلیل nginx روی ۸۰۸۰
  گوش می‌دهد نه ۸۰ — پروسهٔ غیر root اجازهٔ پورت‌های زیر ۱۰۲۴ را ندارد.
- **CSP سخت‌گیرانه** (`web/docker/security-headers.conf`): چون سرویس‌های
  بیرونی را حالا بک‌اند صدا می‌زند نه مرورگر، `connect-src` فقط `'self'`
  است و تنها میزبان بیرونی مرورگر، کاشی‌های نقشه است. سرویس بیرونی تازه
  باید هم‌زمان این‌جا هم اضافه شود، وگرنه مرورگر بی‌صدا بلوکش می‌کند.
- **آپلود عکس تا ۶ مگابایت از پروکسی می‌گذرد** — پیش‌فرض ۱ مگابایتی nginx
  آن را با 413 می‌کشت؛ سقف واقعی را بک‌اند می‌سنجد.

## بک‌اند .NET

بازنویسی کامل است ([سند ۶](docs/06-rewrite-architecture.md)): برنامه‌ریز،
هزینه، مشاور، بهینه‌ساز، عکس چک‌این، پنل مدیریت و احراز هویت کاربر با
«سفرهای من».

```bash
cd backend
dotnet test                      # ۱۴۷ تست
dotnet run --project src/LeaderTrip.Api

cd ../web
npm test                         # ۵۵ تست واحد + ۱۳ سناریوی e2e با Playwright
npm run dev                      # توسعه با پروکسی /api به بک‌اند
```

بدون رشتهٔ اتصال، دادهٔ مرجع از داخل خود اسمبلی خوانده می‌شود و برنامه بدون
PostgreSQL بالا می‌آید.

| اندپوینت | کار |
|---|---|
| `GET /api/reference` | شهرها، خودروها و قیمت‌های پایه |
| `GET /api/pois` | جاذبه‌ها، با فیلتر شهر/دسته/شعاع |
| `POST /api/trips/plan` | ساخت برنامهٔ سفر و تفکیک هزینه |
| `GET /health` | سلامت سرویس |
| `POST /api/trips/optimize` | راه‌های کاهش هزینه، با صرفه‌جویی واقعی |
| `GET /api/pois/discover` | کشف مکان از OpenStreetMap (پیش‌فرض خاموش) |
| `POST /api/admin/prices` | انتشار نسخهٔ تازهٔ قیمت (فقط با کلید) |

پاسخ `POST /api/trips/plan` علاوه بر برنامه و هزینه، هشدارهای لیدر و چک‌لیست
بار را هم برمی‌گرداند — هرکدام با دلیل خودشان.

انتقال دادهٔ ۱۴۳ جاذبه و ۸۵ شهر از نسخهٔ TypeScript با اسکریپت انجام می‌شود، نه
دستی:

```bash
npm run seed:export              # src/data/*.ts → دادهٔ اولیهٔ بک‌اند
```

## رابط تازه (React + MUI)

در `web/` — ویزارد پنج‌گامی، برنامهٔ ساعت‌به‌ساعت با آب‌وهوای هر روز، تفکیک هزینه
با فرمول هر قلم، بهینه‌ساز بودجه، هشدارهای لیدر، چک‌لیست بار، نقشهٔ مسیر، حالت
حین سفر با تسویه‌حساب گروهی، نسخهٔ چاپی، اشتراک‌گذاری با لینک، و کارکرد آفلاین.

**هم‌ترازی با نسخهٔ اول رسیده است.** جز عکسِ چک‌این، هرچه در `src/` بود در `web/`
هم هست: بهینه‌ساز بودجه، ویرایش دستی، نسخهٔ چاپی، اشتراک‌گذاری، حالت حین سفر با
تسویه‌حساب، هشدار گردنه، کشف از OpenStreetMap و یادگیری سلیقه. فهرست کامل در
[سند ۶](docs/06-rewrite-architecture.md) است.

```bash
cd web
npm install
npm run dev        # با پروکسی /api به بک‌اند روی ۵۱۹۹
npm test           # ۴۹ تست واحد
npm run test:e2e   # ۱۱ تست مرورگر واقعی روی بیلد تولید
npm run build
```

React 19 · TypeScript 7 · MUI 9 · TanStack Query · React Hook Form + Zod · Leaflet · Vite 8

**طراحی اختصاصی:** پالت فیروزه/لاجورد/زعفران، نقش گرهٔ هشت‌پر خاتم، و حدود سی
آیکون خطی دست‌ساز (توقف استراحت استکان چای است ☕). گالری آیکون‌ها: `/?icons`
