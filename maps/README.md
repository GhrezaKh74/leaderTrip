# نقشهٔ خودمیزبان ایران

نقشهٔ برداری کامل ایران، روی سرور خودتان — بعد از یک‌بار ساخت، **هیچ درخواستی
به هیچ سرویس بیرونی نمی‌رود**: نه کاشی، نه فونت، نه اسپرایت.

## ساخت (یک فرمان، یک‌بار)

```bash
docker compose --profile tiles up
```

دو کار انجام می‌شود و در volume `tiles-data` می‌نشیند:

| چه | از کجا | حجم تقریبی |
|---|---|---|
| `iran.pmtiles` — کاشی برداری کل ایران تا زوم ۱۵ | استخراج از build.protomaps.com (دادهٔ OpenStreetMap) | ~۱ تا ۲ گیگابایت |
| `assets/fonts` و `assets/sprites` — فونت گلیف و آیکون‌ها | protomaps/basemaps-assets | ~۱۵ مگابایت |

بعد `docker compose up -d` معمولی: nginx مسیر `/tiles/` را از همان volume
استاتیک سرو می‌کند (PMTiles فقط «درخواست Range» می‌خواهد که nginx خودش
بلد است — هیچ سرویس کاشی جدایی در کار نیست) و اپ **خودکار** نقشهٔ برداری
خودمیزبان را با برچسب فارسی بالا می‌آورد.

## چند تصمیم عمدی

- **PMTiles، نه سرور کاشی:** یک فایل استاتیک + Range؛ نه mapnik، نه
  tileserver، نه دیتابیس. کمترین قطعهٔ متحرک، کمترین چیزی که خراب شود.
- **اگر کاشی نبود، اپ نمی‌شکند:** بدون این volume، نقشه همان OSM آنلاین
  قبلی است. سوئیچ خودکار است (یک HEAD به `/tiles/iran.pmtiles`).
- **MapLibre تنبل بار می‌شود:** فقط وقتی کاشی خودی هست و تب نقشه باز است؛
  بازدید اول اپ حتی یک بایت از آن را دانلود نمی‌کند.
- **برچسب‌ها فارسی‌اند** (`name:fa` از OSM، با افزونهٔ RTL از باندل خودمان)
  و حالت تاریک نقشه با تم اپ عوض می‌شود.

## به‌روزرسانی نقشه

دادهٔ protomaps روزانه از OSM ساخته می‌شود. برای نو کردن:

```bash
TILES_BUILD=20261101 docker compose --profile tiles up   # تاریخ ساخت دلخواه
```

فهرست تاریخ‌ها: <https://build.protomaps.com>. حق انتساب «© OpenStreetMap»
روی نقشه می‌ماند — شرط پروانهٔ ODbL است.
